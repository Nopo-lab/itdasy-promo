# 잇데이 홍보 사이트

`https://itdasy.com/` — GitHub Pages, `main` 브랜치 루트에서 자동 배포합니다.

## 콘텐츠 기준

- 무료 회원가입과 스토어 구독 체험은 별개입니다.
- 한국 기준 Pro 월간 9,900원 / 연간 99,000원(부가세 포함).
- 월간 앱 구독은 스토어 계정의 자격 및 구매 화면에 따라 14일 체험이 제공될 수 있습니다. 연간은 체험 없이 즉시 결제됩니다.
- 구독 취소, 환불 요청, 회원 탈퇴는 별도 절차입니다.
- AI 기능은 기능별 전송 안내·동의와 결과 확인을 거쳐 사용합니다. SNS 연동은 계정 유형·승인 권한·제공 상태에 따라 달라집니다.
- 한국어와 영어 문구를 함께 갱신합니다. 기능 선택과 실제 화면 연결을 유지합니다.

## 2026-10-01 확인 근거

- 운영 API `/subscription/plans`: 월간·연간 가격, 무료/Pro의 일일 캡션·배경 제거 한도 및 AI 비서 월간 한도 확인.
- 운영 API `/billing/config`: 웹 결제 비활성 상태 확인.
- `Nopo-lab/itdasy-frontend`의 `app-plan.js`, `app-iap.js`, `IAP_SETUP.md` (`51dd998`): 월간 14일 체험 안내, 상품 ID, 연간 즉시 결제, 결제 경로별 해지 동작.
- 최신 백엔드 `utils/plan_limits.py`: 월간 캡션 150회, 배경 제거 60회의 기본 한도. 환경 설정으로 달라질 수 있어 사이트에도 기본 한도로 안내.
- Apple·Google의 취소·환불 공식 안내와 국가법령정보센터의 전자상거래법. 고객이 따라갈 수 있는 원문 링크는 환불 정책에 포함.

스토어 계정별 체험 자격과 현재 배포·판매 가능 여부는 구매 화면에서 별도 확인해야 합니다. 이 사이트의 가격·체험 안내만으로 스토어 판매 개시를 증명하지 않습니다.

## 정책 페이지

- `privacy.html` / `privacy-en.html`: 앱 및 홍보 사이트 개인정보 처리 안내.
- `terms.html` / `terms-en.html`: 기존 약관과 결제 조건의 설명 정정.
- `refund.html` / `refund-en.html`: 취소·환불 경로와 청약철회 안내.
- `delete-account.html`: 계정 삭제 및 구독 별도 취소 안내.

외부 AI 공급자의 정확한 보관 기간·학습 설정과 국외 이전 계약 근거는 공급자별 계약·프로젝트 설정 증빙을 확인한 뒤 확정해야 합니다. 확인되지 않은 기간, SCC 체결 또는 즉시 완전 삭제를 보장하는 문구를 추가하지 않습니다. 새로운 개인정보 항목·처리 목적·수탁자·요금 조건 도입 시 기존 정책의 사전 고지 및 동의 절차를 적용합니다.

## 브랜드와 앱 화면

앱의 로즈 브랜드 색을 사용합니다. 실제 기능 화면의 출처와 샘플 데이터 범위는 [assets/screens/README.md](assets/screens/README.md)를 참고하세요. 사업자 정보는 홈 페이지 하단에 한 번 표시합니다. 상단의 8개 기능을 선택하면 한 화면에서 실제 앱 캡처가 바뀝니다. 사진 편집은 최신 테스트 앱 화면으로 표시합니다. 중복 기능 목록과 이전 배너를 정리했습니다.

## 2026-10-02 가독성과 화면 비중 정리

홈은 흰색 중심으로 구성하고 앱 로즈 색은 브랜드 강조와 선택 표시에 사용합니다. 기능은 테두리 없는 글자 메뉴로 모아 한 번에 확인할 수 있게 했습니다. 실제 앱 캡처는 모바일 본문 폭을 거의 채우며 PC에서도 확대 배치합니다. 사진 편집기 출처와 테스트 버전 안내는 유지합니다.
